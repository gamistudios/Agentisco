Android · offline-capable · no root

The AI coding agent, Linux terminal and editor
that run entirely on your phone.

Agentisco ships a Debian userland through proot, drives it with an agent that has 21 real tools, and wraps the results in an IDE-grade editor and Git client. Self-updates are verified byte by byte before they install.

Download Agentisco What it does

Requires Android 7.0+ on arm64-v8a or armeabi-v7a.

Built for real work on a real machine

Agent

Multi-turn sessions with streaming reasoning, inline tool cards, approval gates and mid-conversation model switching.

Debian terminal

An interactive shell with a real PTY, project folders mounted at /workspace.

Editor

Syntax highlighting for 26 languages, symbol outline, find & replace, and "Ask Agent" with file context.

Git

Real git: status, diffs, staging, revert, commit messages written by the agent, history.

Projects & build

Disk-measured project metadata, file tree, diff viewer and a build/run centre for npm-style scripts.

Verified updates

Resumable downloads checked against size, SHA-256 and the APK signature before the installer is offered.
